# 🌐 Quanta Coder — Community Website

**Official Website for Quanta Coder — Technocrats Institute of Technology**

Quanta Coder is the official student-driven coding community of **Technocrats Institute of Technology (TIT)**. Our mission is to foster collaboration, innovation, and technical excellence through workshops, hackathons, coding challenges, and resource sharing.

This website serves as the central hub for all community updates, events, and resources, built using modern web technologies for a fast, responsive, and scalable experience.

---

## 🚀 Tech Stack

- **Next.js** — React Framework with server-side rendering & routing  
- **TypeScript** — Type-safe JavaScript development  
- **Tailwind CSS** — Utility-first CSS framework for fast UI development  

---

## 📂 Project Structure

quanta-coder/
├── components/ // Reusable UI components
├── pages/ // Application routes (Next.js)
├── public/ // Static assets
├── styles/ // Global styles
├── utils/ // Helper functions & utilities
├── tsconfig.json // TypeScript config
└── tailwind.config.js // Tailwind CSS config


---

## ⚡ Getting Started

Clone the repository and run the project locally:

git clone https://github.com/your-username/quanta-coder.git
cd quanta-coder
npm install
npm run dev
